# Team Ideas

Template for teammates to claim modules and features. Do not invent ownership — fill in tonight / Sunday.

| Idea | Owner | Module / area | Status |
|------|-------|---------------|--------|
| | | | open |
| | | | open |
| | | | open |

## Status values

- `open` — available
- `claimed` — someone is working it
- `done` — merged / demo-ready
- `parked` — deferred past demo

## Module hook

1. Create `src/modules/<name>.ts` exporting a `HealthModule`.
2. Add it to `src/modules/registry.ts`.
3. It appears on body map, alerts, and timeline automatically.
